# Arduino Robot Car

A school project: an Arduino-controlled robot car, built step by step.
🚧 Work in progress.

## Sketches

- **week01** – reads an analog voltage and turns an LED on above a threshold
- **week02-03** – joystick reading shown on an LCD; a button (interrupt)
  starts a motor test that ramps both motors backward and forward with PWM

## Tech
Arduino Mega (C++), LiquidCrystal, PWM motor control, interrupts
